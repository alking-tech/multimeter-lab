# مختبر الملتيميتر ⚡ Multimeter Lab

مختبر افتراضي تفاعلي لتعلّم القياسات الكهربائية بجهاز الملتيميتر: جهد، تيار، مقاومة، استمرارية، دايود،
قانون أوم، وورشة تبني فيها دوائرك بنفسك. بالعربية والإنجليزية، ويعمل على الجوال وبدون إنترنت.

**مجاني وبدون تسجيل دخول:** افتح الرابط وابدأ.

An interactive virtual lab for learning electrical measurements with a multimeter. Arabic & English, works on phones and offline. Free, no sign-up.
